# かいものルート — スーパー買い物ルート作成アプリ

買い物リストを書くと、**その品物が置かれている売り場を自動で特定し、店内を最短で回れる順番とルート**を作ってくれるモバイルアプリです。

スマホのブラウザで動く PWA（プログレッシブウェブアプリ）なので、ストアの審査なしにすぐ使えます。ホーム画面に追加すればネイティブアプリと同じく全画面で起動し、電波がなくても動きます。データはすべて端末の中だけに保存され、サーバーには送信しません。

---

## 画面と機能

### 1. マップ（店舗マップ作成）

<!-- 通っているスーパーの間取りを、方眼紙を塗る感覚で作ります -->

- 方眼のマスを指でなぞって **商品棚 / 通路 / 壁 / 入口 / レジ / 階段 / エレベーター** を配置します
- 商品棚をタップすると、その棚で **取り扱う商品ジャンル**（1つの棚に複数可）を登録できます
- **棚以外の場所は既定で通路**です。壁は店の外周や立入禁止エリアに使います
- **階ごとにマップを作成**でき、階段・エレベーターは「接続グループ」で階をまたいで結びます。同じグループのもの同士だけが行き来できます
- 1マスの実寸（既定 1.2m）を設定すると、距離と所要時間の目安が実際の店に合います
- 最初からサンプル店舗（2階建て・21売り場）が入っているので、すぐ試せます
- **見取り図からの自動生成（AI）**：店内の見取り図を撮影・アップロードすると、Claude が画像を解析して壁・商品棚・通路・入口・レジ・階段・エレベーターを自動配置します。棚に書かれた文字（「青果」など）があれば読み取って棚名にし、既存のジャンル辞書で自動判定します。利用にはご自身の Anthropic APIキー（[取得はこちら](https://console.anthropic.com/settings/keys)）が必要で、端末内にのみ保存され、画像とともに Anthropic の API に直接送信されます（開発者には送信されません）。生成結果は他の編集操作と同じく「元に戻す」で取り消せます

### 2. リスト（買い物リスト作成）

- 買いたいものをテキストで入力します。**改行や読点で区切ると一度にまとめて追加**できます
- 買ったものはチェックできます。ジャンル別／入力順の切り替え、購入済みの一括削除にも対応
- リストは複数作れ、それぞれに買い物先の店舗を紐づけられます

### 3. ジャンル特定

入力された品目テキストから商品ジャンルを推定します。オフラインで動く辞書ベースの判定です。

- **表記ゆれの吸収** — 全角/半角、カタカナ/ひらがな、半角カナ、`2本` `300g` `×3` などの数量表記、`（低脂肪）`のような括弧書きを取り除いて比較します
- **漢字の読み** — 「ぎゅうにゅう」と入力しても「牛乳」に当たります
- **複合語の解釈** — 日本語の複合語は末尾が主要部になりやすい性質を使い、「塩鮭」は調味料ではなく鮮魚、「野菜ジュース」は野菜ではなく飲料と判定します
- **あいまい一致** — 完全一致・部分一致で決まらない場合は文字 bigram の Dice 係数で近い語を探します
- **学習** — 判定できなかった品目に手動でジャンルを指定すると、その言葉を覚えて次回から自動判定します
- 既定で **23ジャンル・約900語** の辞書を持ち、語彙の追加・削除・ジャンル自体の追加もできます。「ジャンル判定を試す」で、どの語が決め手になったか確認できます

### 4. ルート作成

買い物リストの品物を効率よく買える順番と、店内の通路をたどる経路を作ります。

- 立ち寄り箇所、歩く距離（m）、所要時間の目安、階の移動回数を表示します
- 地図上にルートの線と立ち寄り順の番号を重ねて描きます。階をまたぐ場合はフロアごとに切り替えて確認できます
- 各立ち寄り地点で「ここで買うもの」をその場でチェックできます。チェックすると**残りの品物でルートを組み直します**
- ジャンル未設定の品目、マップに売り場が無いジャンル、通路がつながっておらず到達できない売り場は、理由とともに警告します

## ルート探索のしくみ

1. **グラフ化** — 全フロアの通行可能なマスを頂点、上下左右の移動を重み1の辺とするグラフを作ります。階段・エレベーターは同じ接続グループ同士を結び、階数差に応じた重みを与えます（階段は1階あたり6、エレベーターは待ち時間相当の固定8＋1階あたり2）
2. **立ち寄り候補** — 必要なジャンルごとに、そのジャンルを扱う棚を探し、**棚の前に立てるマス**（棚に接する通路）を候補地点にします。同じジャンルの棚が複数あれば、そのすべてが候補になります
3. **距離表** — 入口・レジ・各候補地点から Dijkstra 法で全点への最短距離を求めます
4. **順番の最適化** — 「各ジャンルからちょうど1地点を選び、入口から出発してレジで終わる最短経路」を解きます（集合TSP / Generalized TSP）
   - **12ジャンル以下** — Held-Karp のビットDPで**厳密な最適解**を求めます
   - **13ジャンル以上** — 最近傍法で初期解を作り、2-opt による順序改善と立ち位置の選び直しを交互に繰り返します
   - レジが複数ある場合は、どのレジで終わるかも含めて最短になる組み合わせを選びます
5. **経路復元** — 決まった順番どおりに Dijkstra の結果から実際に通るマスの列を復元し、地図に描きます

同じ棚に複数のジャンルがある場合（例: レトルトと即席麺が同じ通路）は、1つの立ち寄り地点にまとめて表示します。

## 開発

```bash
npm install
npm run dev        # 開発サーバー
npm run build      # 本番ビルド (dist/)
npm run preview    # ビルド結果の確認
npm test           # 単体テスト
```

Node.js 18 以上が必要です。

### スマホで試す

`npm run dev -- --host` で起動し、同じ Wi-Fi のスマホから表示された URL を開きます。
本番ビルド（`dist/`）は静的ファイルなので、任意の HTTPS ホスティングに置けます。設置後、ブラウザのメニューから「ホーム画面に追加」でインストールできます。

### テスト

`npm test` で70件の単体テストが走ります。

| ファイル | 対象 |
| --- | --- |
| `src/lib/normalize.test.ts` | 表記ゆれの正規化、品目テキストの分割 |
| `src/lib/genre.test.ts` | ジャンル特定（37品目の判定、学習エイリアス、未知語の扱い） |
| `src/lib/route.test.ts` | グラフ構築、階の接続、立ち寄り順、経路の連続性、警告の報告 |
| `src/lib/aiFloorPlan.test.ts` | 見取り図解析結果 (相対座標の区画) をグリッドに焼き込む変換処理 |

テスト用のマップは ASCII アートで書けます（`src/lib/layout.ts`）。`.` が通路、`#` が壁、英字が棚、`E`/`C`/`S`/`V` が入口/レジ/階段/エレベーターです。

```
'#######'
'#E...C#'
'#.a.b.#'
'#######'
```

## 構成

```
src/
  types.ts               データモデル（フロア・棚・設備・リスト・ルート）
  lib/
    normalize.ts         日本語テキストの正規化と類似度
    genre.ts             ジャンル特定
    grid.ts              方眼マップの操作（棚の占有マス、棚の前のマス など）
    pathfind.ts          全フロアのグラフ構築と Dijkstra 法
    route.ts             集合TSP によるルート作成
    layout.ts            ASCII アートからマップを組み立てる
    mapStyle.ts          地図の配色
  data/
    categories.ts        既定の23ジャンルと語彙辞書
    sampleStore.ts       サンプル店舗（2階建て）
  store/useAppStore.ts   アプリ状態（zustand + localStorage 永続化）
  components/            地図描画・ボトムシート・ジャンル選択
  screens/               リスト / ルート / マップ / ジャンル の4画面
```

## データの保存とバックアップ

リスト・マップ・ジャンル辞書は端末の localStorage に保存されます。サーバーには一切送信しません。
「ジャンル」画面の **データ** から JSON で書き出し・読み込みができるので、機種変更の前にバックアップしてください。
